# Tiffany's Mobile Tech

Responsive website for Tiffany's Mobile Tech, with Home, Services, About, and Contact pages.

## Course project

### Project Milestone 2: Styled & Responsive

This 75-point project milestone builds on the portfolio foundation by adding visual styling and a responsive layout. It moves the project from HTML structure toward a polished site that works across common screen sizes. It is part of **Responsive Design with Flexbox & Grid**.

### Homework 3: Responsive Layout

This 50-point homework develops responsive layout skills using modern CSS layout tools and prepares the site to work across devices. The task is to redesign the Homework 2 page using Flexbox, Grid, or both. The page must:

- Use Flexbox or Grid for at least one multi-column layout section.
- Include at least one media query that visibly changes the layout at a defined breakpoint.
- Be usable at 320px (mobile), 768px (tablet), and 1200px (desktop).
- Avoid horizontal scrolling and overlapping elements at all three viewport widths.

Test by resizing a browser or using DevTools device emulation. Submit this repository's GitHub URL. Late submissions are accepted until November 8 at 10:59 PM; resubmissions are not allowed.

## Responsive layout

The site uses CSS Grid and Flexbox, with layouts tuned for the assignment's target widths:

- **320px mobile:** navigation stacks, content grids become single-column, and buttons fill the available width.
- **768px tablet:** service, value, and stats cards use two columns; wider sections adapt to a single column.
- **1200px desktop:** multi-column layouts expand for the available space.

The contact details can wrap long text on narrow screens to prevent horizontal scrolling.
